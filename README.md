# Cờ Vua Chiến Binh ♟️

Trang cờ vua 1 file HTML cho Ken (lớp 1) và Na (lớp 5): học chơi, chơi với máy, 2 bạn cùng máy, đấu online qua mã phòng.
Bàn cờ 3D (Three.js), 9 bộ quân, hoạt cảnh đấu kiếm khi ăn quân, nhạc nền, đọc nước đi tiếng Việt.

- Chơi: https://cqv888.github.io/co-vua-chien-binh/
- Sửa tiếp: sửa trong `src/`, chạy `bash src/build.sh` để tạo lại `index.html`, rồi push. Xem `HANDOFF.md`.
